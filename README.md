This project applies machine learning techniques for customer segmentation, aiming to group customers into distinct clusters based on their purchasing behavior and demographic attributes. It demonstrates the full pipeline of data preprocessing, clustering with K-Means, and analyzing cluster characteristics to uncover meaningful patterns. Using Python libraries such as Pandas, NumPy, Scikit-Learn, Matplotlib, and Seaborn, the notebook shows how businesses can better understand their customer base and design targeted marketing strategies. The project serves as a practical introduction to unsupervised learning and highlights the value of clustering in real-world applications like retail and customer relationship management.
